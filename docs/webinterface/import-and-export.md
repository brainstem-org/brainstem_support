# Import and export
{: .no_toc}

Getting data into BrainSTEM in bulk and out again: the import grid and CSV import, the SoftMouse colony import, and the print, Word, spreadsheet, JSON and STAR Methods exports.

- [__Import tool__]({{"webinterface/import-tool/"|absolute_url}}): Batch entry in a grid with validation before anything is written, and CSV import from downloadable templates
- [__SoftMouse integration__]({{"webinterface/softmouse/"|absolute_url}}): Importing animals, studies, cages and protocols from SoftMouse as subjects, cohorts, housing logs and licenses, by API or Excel export
- [__Exports and reports__]({{"webinterface/exports-and-reports/"|absolute_url}}): Print and Word exports of single or selected entries, spreadsheet exports, **Download project data** and the STAR Methods report
