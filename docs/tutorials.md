# Tutorials
{: .no_toc}

Step-by-step guides for BrainSTEM, from your first project to exports and AI tools. New to BrainSTEM? Follow the learning path below in order: each tutorial builds on the records the previous ones created. The workflow tutorials use the same example lab, so the setups, inventories and storage you create early on are the ones they select later.

## Learning path

### 1. First steps
{: .no_toc}

1. [**Get started!**]({{site.baseurl}}/tutorials/get_started/): Create an account, join a group, and create your first project, subject and session.
2. [**Manage Groups**]({{site.baseurl}}/tutorials/managing-groups/): Create your lab's group, invite members and assign manager and owner roles.

### 2. Set up your lab
{: .no_toc}

3. [**Lab Infrastructure**]({{site.baseurl}}/tutorials/setting-up-lab-infrastructure/): Setups, equipment, inventories and consumable stocks, including catalog probe designs.
4. [**Behavioral Assays**]({{site.baseurl}}/tutorials/behavioral-assays/): Define the behavioral tasks your sessions refer to.
5. [**Managing Data Storage**]({{site.baseurl}}/tutorials/managing-data-storage/): Describe where your data files live and link storage locations to sessions.
6. [**Manage Projects**]({{site.baseurl}}/tutorials/managing-projects/): Project permissions, membership and publications.

### 3. Record a complete experiment
{: .no_toc}

Pick the workflow closest to your own experiments; each one goes from subject to export.

- [**Ephys Workflow**]({{site.baseurl}}/tutorials/electrophysiology-workflow/): A theta maze study with a silicon probe implant, its experimental interface, sleep and behavior sessions.
- [**2P Imaging Workflow**]({{site.baseurl}}/tutorials/two-photon-imaging-workflow/): A visual cortex study with a virus injection, a cranial window and two-photon imaging sessions.
- [**Ex vivo workflow**]({{site.baseurl}}/tutorials/specimen-workflow/): Specimen sets derived from a subject, specimen procedures with stages and materials, specimen logs and a specimen-based session.

### 4. Share and export
{: .no_toc}

- [**Share data publicly**]({{site.baseurl}}/tutorials/sharing-project-publicly/): Make a project and its personal attributes public, and what the public portal shows.
- [**Exporting to NWB**]({{site.baseurl}}/tutorials/exporting-to-nwb/): Download a project or session export and convert it to NWB files with brainstem-nwb.

## When you need them

- [**Resources & Taxonomies**]({{site.baseurl}}/tutorials/submit-resource-and-taxonomies/): Add a missing consumable, hardware device, species, strain or publication to the shared catalogs, with RRID and DOI lookups.
- [**Working with AI**]({{site.baseurl}}/tutorials/working-with-ai/): The in-app assistant, the MCP server for Claude and Cursor, and the agent skills for coding agents.

Looking for a specific screen or option rather than a walkthrough? See the [Web interface]({{site.baseurl}}/webinterface/) pages, or the [FAQ]({{site.baseurl}}/faq/) for common questions.
