<!-- Introductions for the DataAcquisition schema types, used by scripts/build_reference_docs.py when the schema itself has no description. One "## group: <group name>" section per group (exact group name from the input), one "## <TypeCode>" section per type (exact code). -->

## group: Electrophysiology
Recordings of electrical activity, from scalp EEG and peripheral nerve signals to extracellular and intracellular recordings of neurons.

## group: Optical Imaging
Fluorescence and optical recordings, from fiber photometry and miniscopes to confocal, light field and one-, two- and three-photon microscopy.

## group: Magnetic and Functional Imaging
Structural and functional magnetic resonance imaging and magnetoencephalography.

## group: Tomography and Ultrasound
Tomographic and ultrasound imaging, including CT, PET, SPECT, optical coherence tomography and functional ultrasound.

## group: Audio and Behavior Tracking
Audio recordings and video or tracking data that capture the subject's sounds and behavior.

## group: General and Time-Series Data
Sampled signals that no more specific acquisition type covers, such as analog inputs and sensor streams.

## Audio
Documents an audio recording, such as vocalizations or task sounds, with the file format, compression and codec, bit depth, channel and sample counts and sampling rate.

## BehavioralTracking
Documents a file of behavioral tracking data, stored as video or another data format, with the file format, compression, frame count, frame resolution and frame rate.

## ComputedTomography
Documents a CT scan, for example to localize skull landmarks or implants, with the file format, compression, frame count and rate, image resolution and imaging depth.

## ConfocalMicroscopy
Documents confocal image data, including time-lapse series, with image resolution, frame count and rate, laser power, excitation wavelength, imaging depth and voxel size.

## Electroencephalography
Documents an EEG recording, with the file format, data type, channel and sample counts, sampling rate, least significant bit and electrode groups.

## Electroneurogram
Documents a recording of peripheral nerve activity, for example from a nerve cuff, with the file format, data type, channel and sample counts, sampling rate, least significant bit and electrode groups.

## ExtracellularEphys
Documents an extracellular recording of spikes and local field potentials, for example from silicon probes or tetrodes, with the file format, data type, channel and sample counts, sampling rate, least significant bit and electrode groups.

## FiberPhotometry
Documents a fiber photometry recording of bulk fluorescence through an implanted optic fiber, with the file format, frame count and rate, laser power and excitation wavelength.

## FunctionalMagneticResonanceImaging
Documents a functional MRI scan, such as a BOLD time series, with the file format, frame count and rate and image resolution. Use magnetic resonance imaging for structural scans.

## FunctionalUltrasoundImaging
Documents a functional ultrasound imaging session, which tracks hemodynamic changes in the brain, with the file format, frame count and rate, image resolution and imaging depth.

## GeneralTimeSeries
Use for sampled signals that no more specific acquisition type covers, such as analog inputs or sensor streams. Captures the file format, data type, channel and sample counts, sampling rate, least significant bit and channel groupings.

## IntracellularEphys
Documents an intracellular or patch-clamp recording, with the file format, data type, channel and sample counts, sampling rate and least significant bit.

## LightFieldMicroscopy
Documents light field microscopy data, which captures volumetric fluorescence in single exposures, with image resolution, frame count and rate, laser power, excitation wavelength, imaging depth and voxel size.

## MagneticResonanceImaging
Documents an MRI scan, with the file format, image resolution, frame count and rate, imaging depth and static magnetic field strength. Use functional magnetic resonance imaging for BOLD time series.

## Magnetoencephalography
Documents an MEG recording of the magnetic fields produced by neural currents, with the file format, frame count, sampling rate (recorded as frame rate) and sensor array resolution.

## Miniscope
Documents a recording from a head-mounted miniature microscope, typically calcium imaging in freely moving animals, with the video format, frame count, resolution, frame rate and imaging depth.

## OpticalCoherenceTomography
Documents optical coherence tomography data, with the light source center wavelength and bandwidth, axial and lateral resolution, imaging depth, scan pattern and area and the number of averages.

## PositronEmissionTomography
Documents a PET scan, which images the distribution of a radiotracer, with the file format, frame count and rate and image resolution.

## SinglePhotonEmissionComputedTomography
Documents a SPECT scan, which images the distribution of a gamma-emitting radiotracer, with the file format, frame count and rate and image resolution.

## SinglePhotonMicroscopy
Documents one-photon fluorescence microscopy data, with image resolution, frame count and rate, laser power, excitation wavelength, imaging depth and voxel size.

## ThreePhotonMicroscopy
Documents three-photon microscopy data, used to image deeper than two-photon excitation allows, with image resolution, frame count and rate, laser power, excitation wavelength, imaging depth and voxel size.

## TwoPhotonMicroscopy
Documents two-photon laser-scanning microscopy data, such as in vivo calcium imaging, with image resolution, frame count and rate, laser power, excitation wavelength, imaging depth and voxel size.

## VideoTracking
Documents a video recorded to track the subject's position or behavior, with the file format, compression, frame count, frame resolution and frame rate.
